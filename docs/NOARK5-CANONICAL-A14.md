# Ferdigstillingsutkast (a14)

`noark5_reports/COMPLETION_DECISION_DRAFT.html` genereres separat fra KS-rapporten. Utkastet leser kontrollmatrisen og eksplisitt analyserte eksterne data og viser kildefunn som uavklarte forhold, ikke som vedtak.

KS-rapportens fil og SHA-256 refereres dersom den finnes; dette innebærer ikke at den er akseptert eller oppdatert. Det registreres ikke beslutning i DWM, eller i sak-/arkivsystem, og filen er **ikke** ferdigstillingsvedtak eller klarering for AIP.

Før faktisk godkjenning må arkivskapers aksept, vurdering av avvik, anvendelig kontrollprofil, depotets beslutning og journalføringsreferanse dokumenteres i egen senere arbeidsflyt.
