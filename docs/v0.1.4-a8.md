# v0.1.4-a8

a8 prioriterer praktisk kontroll og rapportering for reelle Noark 5-uttrekk.

## Kontrolloversikt per RUN

Når en RUN avsluttes bygges en egen Noark 5-kontrolloversikt fra de allerede
genererte `depot_validation_report.json`-filene.

Det kjøres ikke ny XML-, XPath- eller telleanalyse.

Oversikten viser per jobb:

- jobb og kilde,
- jobbstatus,
- teknisk kontrollstatus,
- antall tester OK / feil,
- reconciliation mismatch,
- antall vurderingspunkter,
- depotets vurderingsstatus,
- lenke til den komplette depotvalideringsrapporten.

Statusene `OK`, `VURDER`, `FEIL`, `MANGLER` og `UKJENT` er en operativ
kontrollklassifisering. De er ikke automatisk faglig godkjenning av uttrekket.

## Fleksibel lagring

Kontrolloversikten lagres i den eksisterende konfigurerbare rollen for
overordnede kjørelogger (`run_log_dir`). Ingen ny fast disk, stasjonsbokstav,
serversti eller AIP-struktur innføres.

De individuelle Noark 5-rapportene fortsetter å ligge under den effektive
`Work - operations`-rollen for hver jobb.

## GUI

Jobber-vinduet får knappen `Kontrolloversikt`, som åpner siste genererte HTML-
oversikt. Knappen er deaktivert dersom ingen oversikt finnes.
