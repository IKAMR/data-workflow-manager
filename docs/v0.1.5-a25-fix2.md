
# v0.1.5-a25 fix 2

Den faktiske Resultatvisninger-flyten fra kontrolloversikten går via
`DirectDepotAssessmentDialogA19`.

Tidligere a25-fix forsøkte å bytte dialogklasse indirekte i runtime, men den
direkte depotvurderingsdialogen overstyrer selv `_open_result_views()` og
opprettet eksplisitt `DepotResultViewsDialogA19`.

Denne fixen retter den autoritative ruten direkte:

`DirectDepotAssessmentDialogA19 -> DepotResultViewsDialogA20`

Ingen Noark 5- eller Arkade 5-tester må kjøres på nytt. Dette er bare GUI-routing
mot allerede genererte depotrapporter og allerede importert ekstern evidens.
