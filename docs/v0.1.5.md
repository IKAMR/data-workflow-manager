# v0.1.5

Data Workflow Manager v0.1.5 videreutvikler Noark 5-kontroll med komplett og sporbar integrasjon av Arkade 5 som ekstern evidenskilde.

## Hovedendringer

- dokumentert Arkade 5-testkatalog og eksplisitt mapping mot DWM-kontroller
- import og tapsfri normalisering av Arkade 5-resultater med kildeproveniens
- samlet dekning, gap- og overlappmodell for DWM og Arkade 5
- Arkade 5-evidens integrert i depotvalideringsrapport og resultatvisninger
- filtrering, detaljvisning, analyse og portabel eksport av ekstern evidens
- dekningspolicy, integrasjonskontroll, praktisk akseptanse og release readiness
- støtte for Arkade 5 v2.13.1 med v2.13.0 som dokumentert semantisk baseline
- forbedret og mer lesbar presentasjon av gap og overlapp med testnavn for både Arkade 5 og DWM

v0.1.5 er verifisert gjennom alpha-serien fram til v0.1.5-a27.
