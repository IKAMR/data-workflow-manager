# Terminologinotat – U1 og U2

`U1` og `U2` er lokale/historiske betegnelser fra IKAMRs egne XPath/XQuery-definisjoner for KDRS Query. De er ikke etablerte Noark 5-begreper eller en generell KDRS-navnestandard.

Nye arkitektur-, analyse-, view- og rapportbegreper skal navngis etter faglig funksjon. U1/U2 beholdes bare der historisk kildehenvisning, regresjon og migreringssporbarhet gjør det nødvendig.

## Profilarkitektur

Historiske U1/U2-referanser skal være gjenfinnbare gjennom Noark 5-profilmanifestet, men nye profilkomponenter skal navngis etter faglig funksjon. Se `docs/PROFILE-ARCHITECTURE.md` og `docs/NOARK5-PROFILE-ARCHITECTURE.md`.

## a24-status

Fra a24 er U01/U02 ikke del av ordinær kjøring. Betegnelsene beholdes bare i legacy-definisjoner, regresjonskontrakt og historisk dokumentasjon. Nye brukerflater og rapporter skal bruke funksjonelle navn.
