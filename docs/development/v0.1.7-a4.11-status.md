# a4.11 – Tallformatering og videre integrasjon

- Feltet **Saker** er eget målefelt (`case_count`) – ikke det samme som mapper (`folder_count`).
- Vis numeriske antall med mellomrom som tusenskille. JSON lagrer fortsatt heltall.
- Denne deltaen formaterer kandidater i KDRS-velgeren og oversiktstallet i HTML.
- Full automatisk overføring av KDRS-felt til depotrapport, bytte av jobb i Resultatvisninger og oppstarts-/fokusregresjoner krever videre implementasjon.
- Ikke flytt eller slett historiske eksterne evidens-/metadatafiler automatisk.
