# v0.1.6-a4 – native window focus fix

## Problem

Etter at de store Noark 5-vinduene ble gjort til normale native vinduer kunne Windows aktivere foreldrevinduet igjen etter opprettelse. Resultatet var at:

- Depotvurdering kunne åpne bak vinduet det ble startet fra.
- Vurdering av uttrekk kunne åpne bak Depotvurdering.

Selve vinduene eksisterte og hadde korrekt native Windows-dekorasjon; problemet var Z-order/fokus.

## Korrigering

- den globale `<Map>`-hooken brukes fortsatt bare til plassering
- de fire store a4-arbeidsvinduene aktiverer seg eksplisitt etter mapping
- på Windows brukes en kortvarig `topmost`-puls for å få korrekt foreground/Z-order
- `topmost` slås deretter eksplisitt av igjen
- vinduet avslutter med vanlig `lift` og fokus
- macOS/Linux bruker bare vanlig deiconify/lift/fokus uten Windows-spesifikk puls

Dette gjør ikke vinduene permanent «alltid øverst».
