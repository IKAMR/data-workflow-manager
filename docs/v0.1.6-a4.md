# v0.1.6-a4

## Mål

Gjøre de store Noark 5-arbeidsvinduene til normale native plattformvinduer og gjøre arkivdelvisningen til en faktisk arbeidsflate for vurdering.

## Korrigert vindusimplementasjon

Første a4-forsøk endret Tk sitt `transient`-forhold fra den globale `<Map>`-hooken. Det var for aggressivt: vindusstil ble endret mens CustomTkinter fortsatt mappet vinduet, og enkelte store vinduer kunne blinke og forsvinne.

Korrigert a4 gjør derfor følgende:

- global `<Map>`-hook brukes igjen **kun til vindusplassering**
- native/maximerbar stil aktiveres eksplisitt etter konstruksjon på de store Noark 5-arbeidsvinduene
- Resultatvisninger, Depotvurdering og Noark 5-kontrolloversikt omfattes
- popup/tooltips med `overrideredirect` berøres ikke
- Windows får normal minimer/maksimer/lukk
- macOS/Linux beholder plattformens native window-manager-dekorasjoner
- mønsteret kan senere utvides kontrollert til øvrige større arbeidsvinduer

## Arkivdelvisning

a4 bygger videre på a3 og bruker eksisterende sporbarhet i depotrapporten til å finne den allerede materialiserte `depot.json`-presentasjonen.

For valgt arkivdel vises:

- innhold og omfang
- bevaring, skjerming og kassasjon
- dokumentformat når dette finnes i materialisert presentasjon
- feltstatus når data ikke er tilgjengelig
- kildetest og source path per felt
- kompakt sporbarhet nederst

Manglende data forklares med statuser som `Ikke materialisert`, `Mangler for arkivdelen` og `Kildetest mangler`.

## Prinsipp

Visningen kjører ingen ny XML/XPath-analyse. Arkade 5 forblir ekstern evidens og påvirker ikke automatisk DWM-status eller depotets faglige vurdering.
