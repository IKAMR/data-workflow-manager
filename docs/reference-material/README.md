# Referansemateriale

Denne mappen inneholder normalisert arbeids- og referansemateriale for utvikling av Data Workflow Manager. Materialet er ikke autoritative standarder med mindre dette er uttrykkelig angitt.

## Struktur

- `checklists/sjekkliste.docx` - normalisert versjon av dagens sjekkliste, med kort header for arkivskaper/system/depot/avtale.
- `checklists/sjekkliste-mets.docx` - alternativt utviklingseksempel med utvidet METS-basert header.
- `intake/innlevering.docx` - normalisert versjon av eksisterende skjema «Informasjon om innlevering», med samme struktur og veiledning.
- `intake/innlevering-ny.docx` - forslag til ny og mer strukturert versjon.
- `approval/godkjenningsbrev-utkast.docx` - siste arbeidsutkast til godkjenningsbrev. Det er foreløpig utviklingsmateriale og ikke kvalitetssikret som standard.
- `mets/examples/` - syntetiske METS-eksempler for utvikling og testing.
- `noark/` - arbeidsreferanser samlet fra åpne spesifikasjoner og faglig praksis.

## Prinsipper

METS `LABEL` og `DELIVERYSPECIFICATION` skal holdes som separate felt selv når verdiene er identiske. Eksplisitte metadatafelt skal ikke erstattes av verdier utledet fra fritekst. Uoverensstemmelser skal kunne vises som vurderingspunkter.

Godkjenningsbrev, sjekkliste, innleveringsinformasjon og tekniske vedlegg er foreløpig utviklingsmateriale. Struktur, standardtekster, dataavledede felt og faglige fritekstvurderinger skal kvalitetssikres videre før en endelig rapportmodell fastsettes.
