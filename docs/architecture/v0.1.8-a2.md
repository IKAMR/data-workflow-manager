# DWM v0.1.8-a2 – kompakt arbeidsflate

## Formål

Første praktiske GUI-trinn for bruk på én laptopskjerm. DWM bruker fortsatt
CustomTkinter i dette trinnet; arkitekturen fra a1 er forberedt for flere
GUI-implementasjoner, men all eksisterende jobbkjøring skal forbli uendret.

## Implementert

- **Jobber** er en innebygd visning i hovedvinduet og vises ved oppstart.
- **Arbeidsflyt** viser de eksisterende Source-, operasjons- og loggpanelene.
- **Handlinger** gjenbruker eksisterende kommandoer fra den historiske
  topplinjen; **Vis full topplinje** gir tilgang til alle gamle kontroller.
- **Full jobbliste** åpner fortsatt det eksisterende avanserte vinduet for
  Mapper, Start valgte, jobbhandlinger og annet som ennå ikke er flyttet.
- Tidligere automatisk gjenåpning av det separate jobblistevinduet under
  oppstart er slått av; bruker kan åpne vinduet eksplisitt.
- Innebygde jobbrader oppdateres med et billig, skrivebeskyttet snapshot uten
  disksøk eller metadataimport. Aktive jobber markeres med ramme, ikke lys
  bakgrunn med uleselig tekst.
- Normal vindusstørrelse begrenses til aktuell skjerms arbeidsområde ved
  oppstart. Eksisterende lagret vindusgeometri og maksimalisering håndteres
  ellers av tidligere kode.

## Bevisste avgrensninger

- a2 **erstatter ikke** den fullstendige jobblistens samtlige funksjoner.
- Ingen endring i jobbutførelse, Noark 5, Arkade 5, KDRS Query,
  rapportering, jobblisteformat, lagringsprofiler eller brukerdata.
- Nye GUI-visninger bruker fortsatt etablert GUI-runtime som autoritativ
  jobbtilstand. Ingen parallell DwmApplication-instans opprettes i a2.
- Det nye a1-API-et brukes ikke ennå til å drive hele GUI-et; dette krever en
  kontrollert migrering av batch, kontrollpunkter og lagring.
- a2 er ikke testet på Windows med faktiske skjermoppsett i utviklingsmiljøet.

## Manuell akseptansetest (Windows)

1. Fra v0.1.8-a1: pakk a2-delta over repoet og kjør `test.bat`.
2. Start `start.bat`. Kontroller at **Jobber** vises inne i hovedvinduet og at
   tidligere separat Jobbliste ikke åpnes automatisk.
3. Åpne en eksisterende `.n5jobs` og velg JOB-002. Kontroller at
   **Arbeidsflyt** vises med samme Source, operasjoner og logg som tidligere.
4. Gå tilbake til **Jobber**. Kontroller at status, % og sti stemmer.
5. Velg **Full jobbliste** og test minst Mapper, Start valgte og rapport.
6. Kontroller **Handlinger** og **Vis full topplinje**.
7. Test på 1366×768 med 125 % eller 150 % skalering og på 1920×1080.
8. Koble fra sekundær skjerm; kontroller at hovedvinduet er synlig etter
   ny oppstart. Test gamle resultatvinduer separat – de er ikke refaktorert.
