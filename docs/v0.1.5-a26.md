# v0.1.5-a26

Retter krasj ved åpning av `Gap og overlapp`.

Årsak:
`depot_result_views_a20.py` bruker de semantiske fontrollene
`theme.HEADER_SIZE` og `theme.BODY_SIZE`, mens `gui/theme.py` bare hadde
`TITLE_SIZE`, `SECTION_SIZE`, `NORMAL_SIZE` og `SMALL_SIZE`.

Fiks:
- `HEADER_SIZE = TITLE_SIZE`
- `BODY_SIZE = NORMAL_SIZE`
- versjon oppdatert til `0.1.5-a26`
- regresjonstest for fontrollene

De mange etterfølgende `ZeroDivisionError`-meldingene fra CustomTkinter var
følgesymptomer etter at `CTkToplevel`-konstruksjonen avbrøt midt i opprettelsen.
Den opprinnelige feilen er `AttributeError` for `HEADER_SIZE`.

Ingen Noark-/Arkade-analyse trenger kjøres på nytt. Test:
`Resultatvisninger -> Ekstern evidens -> Avansert -> Gap og overlapp`.
Dialogen skal åpne foran, vise lastetekst og deretter resultatet.
