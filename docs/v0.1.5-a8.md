
# v0.1.5-a8

A8 gjør Arkade 5-evidensen portabel og gjenbrukbar utenfor den aktive DWM-jobben.

## Lagt til

- portabel Arkade 5-evidenspakke som ZIP
- pakkemanifest med SHA-256 og filstørrelse
- original bevart Arkade-rapport per import
- tapsfri normalisering per import
- reconciliation når den finnes
- combined coverage per import
- pinnet Arkade-testkatalog, DWM/Arkade-mapping og coverage-modell i pakken
- GUI-handling `Eksporter evidenspakke...`
- additive GUI-lag `a18` og `persistent_app_a50`

## Ikke endret

- ingen nye DWM Noark 5-tester
- ingen Arkade-test reimplementert
- Arkade blir ikke DWM-masterresultat
- ingen automatisk depotgodkjenning eller avvisning
