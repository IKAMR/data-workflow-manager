# v0.1.6-a12

Alle applikasjonens CTkToplevel-dialoger skal på Windows opptre som vanlige desktopvinduer med minimer, maksimer/gjenopprett og lukk.

Implementasjonen er sentral: på Windows ignoreres `transient(master)` for app-dialoger, og dialogene holdes resizable. Modalitet via `grab_set()` beholdes der den allerede brukes. Linux/macOS beholder eksisterende Tk/CustomTkinter-semantikk.

Ingen Noark 5-, depot-, Arkade 5- eller rapportlogikk endres.
