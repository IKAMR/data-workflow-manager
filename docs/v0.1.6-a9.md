# v0.1.6-a9

## Mål

Gjøre det umiddelbart synlig hvilket datagrunnlag som mangler for hver arkivdel. a9 introduserer ingen ny test eller faglig konklusjon.

## Endringer

- Arkivdelskort viser navn på manglende nøkkelfelt.
- Høyresiden får seksjonen **Manglende datagrunnlag**.
- For hvert manglende felt vises source test-id/source path når dette finnes.
- `0` er eksplisitt en gyldig materialisert verdi; bare `None` regnes som manglende.
- Filteret **Komplett** endres til **Alle nøkkelfelt** for å unngå faglig overtolkning.
- Manglende materialisering skilles eksplisitt fra testfeil og faglige avvik.
