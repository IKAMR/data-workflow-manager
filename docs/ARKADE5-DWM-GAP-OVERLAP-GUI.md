# DWM / Arkade 5 – gap og overlapp i GUI

v0.1.5-a10 gjør den statiske gap- og overlappanalysen fra a9 tilgjengelig fra depotrapportens eksterne evidensvisning.

Visningen skiller mellom dokumenterte DWM-gap som Arkade 5 dekker og kontroller der DWM og Arkade overlapper. Den viser eksplisitt at dette er implementasjonskunnskap, ikke bevis på at en test er kjørt i en bestemt jobb.

Arkade-, DWM- og historiske KDRS-identifikatorer holdes adskilt. Delvis og komplementær dekning beholdes som to kilder og blir ikke presentert som ekvivalens.
