# v0.1.4-a10

a10 gjør Noark 5-kontrolloversikten til en faktisk arbeidsflate i appen.

## Kontrolloversikt i appen

Knappen `Kontrolloversikt` åpner nå en egen dialog i Data Workflow Manager i
stedet for å sende brukeren direkte til nettleseren.

Dialogen viser den allerede genererte RUN-kontrolloversikten og kjører ingen ny
XML/XPath-analyse.

Per jobb vises blant annet:

- kontrollstatus,
- antall arkivdeler,
- tester OK / feil,
- reconciliation mismatch,
- vurderingssaker,
- underliggende funn,
- kilde og sentrale omfangstall,
- lenke til den komplette depotrapporten.

## Arbeidsliste

Jobbene sorteres slik at oppfølging kommer først:

`FEIL -> VURDER -> MANGLER -> UKJENT -> OK`

Det kan filtreres på status og søkes i jobb, navn, kilde og statusmelding.

Den opprinnelige HTML-kontrolloversikten beholdes og kan åpnes med
`HTML-oversikt`. a10 endrer derfor ikke rapportformatet eller lagringsmodellen.

## Avgrensning

a10 endrer ikke batchmotor, workflowmotor, ressursstrategi eller Noark 5-
testberegning. Fokus er presentasjon og praktisk gjennomgang av allerede
genererte kontrollresultater.
